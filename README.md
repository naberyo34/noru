# Noru - Rhythm Game

8レーンの2Dドット絵リズムゲーム

**開発者・AIエージェント向け情報は [AGENTS.md](AGENTS.md) を参照してください。**

---

## 🎮 ゲーム概要

Noruは、ビートマニアスタイルの8レーンリズムゲームです。ドット絵の世界観で、音楽に合わせてノートを叩き、スコアを競います。

### コンセプト
- **ドット絵表現**：スーファミ〜GBA風のレトロな雰囲気
- **高精度音楽同期**：Web Audio APIによるミリ秒単位の正確な同期
- **拡張性重視**：将来の機能追加を見越した設計

## 譜面データ形式

譜面は `public/assets/charts/` にJSON形式で配置します：

```json
{
  "metadata": {
    "title": "楽曲タイトル",
    "artist": "アーティスト名",
    "audioFile": "assets/audio/song.wav",
    "bpm": 120,
    "timeSignature": [4, 4],
    "offset": 0
  },
  "notes": [
    { "lane": 0, "timing": 2000 },
    { "lane": 1, "timing": 2500 }
  ]
}
```

- `lane`: レーン番号（0-7）
- `timing`: ノート出現タイミング（ミリ秒）
- `offset`: 音楽とノートの同期オフセット調整（ミリ秒）

## 設定のカスタマイズ

ゲームの設定値（レーン幅、ノート速度、判定ウィンドウなど）は全て `src/config/GameConfig.ts` に集約されています。

```typescript
// 例：判定を甘くする
export const DEFAULT_JUDGMENT_WINDOW = {
  perfect: 50,  // ±50ms（デフォルト: 30ms）
  great: 100,   // ±100ms（デフォルト: 60ms）
  // ...
};

// 例：ノート速度を変更
export const GAMEPLAY = {
  NOTE_SPEED: 200,  // デフォルト: 160
  // ...
};
```

## 楽曲の追加方法

### 1. 音楽ファイルの配置
`.wav`ファイルを `public/assets/audio/` に配置

### 2. 譜面JSONの作成
`public/assets/charts/` に譜面ファイルを作成（形式は上記参照）

### 3. 楽曲リストへの登録
`public/assets/songs.json` に楽曲情報を追加：

```json
{
  "id": "your-song",
  "title": "Your Song Title",
  "artist": "Artist Name",
  "bpm": 140,
  "audioFile": "assets/audio/your-song.wav",
  "difficulties": [
    {
      "level": "HARD",
      "stars": 7,
      "chartFile": "assets/charts/your-song-hard.json"
    }
  ]
}
```

## アーキテクチャ

### コアロジックとViewの分離

- **Core Layer**: View非依存のゲームロジック（`src/core/`）
  - 譜面データ構造
  - 音楽同期エンジン
  - 判定システム
  - スコア計算

- **View Layer**: Phaser 3による描画とUI（`src/scenes/`）
  - ゲームシーン
  - 入力処理

この設計により、将来的に譜面エディタを別のUIフレームワーク（React等）で実装することも容易です。

## 🎨 ドット絵アセットについて

現在はプレースホルダー（シンプルな四角形）を使用していますが、将来的にドット絵アセットに差し替え可能な設計になっています。

### 推奨アセット仕様
- **ノート**：24×24px
- **キャラクター**：32×32px〜64×64px
- **背景**：320×240px（タイル可能）
- **フォーマット**：PNG（透過対応）

Phaserの`AnimatedSprite`を使用することで、BPM同期のアニメーションも実装可能です。
